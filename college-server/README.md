# Сервер колледжа: этап 1

1. Скачайте `setup-stage1.sh` на флешку (на GitHub: кнопка **Download raw file**, не копируйте текст через буфер).
2. Вставьте флешку в сервер и выполните:
   ```bash
   lsblk                         # найдите флешку, обычно sdb1 или sdc1
   sudo mount /dev/sdb1 /mnt     # подставьте своё имя
   sudo sed -i 's/\r$//' /mnt/setup-stage1.sh
   sudo bash /mnt/setup-stage1.sh
   ```
3. Займёт 10–30 минут. В конце на флешке появится `report-....txt`. Пришлите его содержимое.
4. Перезагрузка: `sudo umount /mnt && sudo reboot`.

Скрипт не трогает диски и данные, ничего не удаляет и не поднимает туннель.
